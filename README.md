# For Mahima ✦

A standalone birthday surprise website created by Daood.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. The site URL will be: https://drush3446-hash.github.io/Mahima-/

The photo frames preview selected images locally in the visitor's browser. Photos are not uploaded or stored by this website.
